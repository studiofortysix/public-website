SPAM / RELIABILITY CONTROLS
- Server-side Turnstile success, exact contact action and exact origin/hostname.
- Same-origin HTTPS requests only; no local hostnames in production configuration.
- Honeypot, bounded fields/JSON body, minimum elapsed time, no unexpected fields.
- Netlify rate limit: 5 requests per60 seconds per IP/domain.
- Official test secrets rejected in production. Missing configuration fails closed.
- Branch/unpublished Netlify deploy contexts cannot forward to HubSpot.
- Original live HubSpot form ID is always refused.
- No automatic retry. Uncertain delivery locks repeat submission and offers email.
- Success is shown only after an explicit server acceptance response.

Scope: these checks protect the website's endpoint. HubSpot's unauthenticated
Forms API can also receive direct requests when its form identifiers are known;
those requests do not pass through this handler. A form ID is not a credential.
Do not claim that Turnstile protects every possible route into HubSpot. Check
HubSpot's own spam handling and monitor the dedicated form after activation.
